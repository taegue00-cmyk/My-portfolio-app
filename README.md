# My Portfolio

세 가지 사이드 프로젝트를 소개하는 에디토리얼 스타일의 개인 포트폴리오 메인 페이지입니다.

## 주요 특징

- 세리프 대형 타이틀과 화이트 카드 기반의 에디토리얼 케이스 스터디 레이아웃
- 프로젝트 카드 3종 (환율 변환기 / 스네이크 게임 / 홍보자동화) 클릭 시 해당 프로젝트로 이동
- 스크롤 시 카드가 부드럽게 떠오르는 등장 애니메이션
- 모바일 반응형 레이아웃

## 소개하는 프로젝트

| 프로젝트 | 설명 | 연결 방식 |
|---|---|---|
| 환율 변환기 | 실시간 환율로 금액을 계산하는 웹 유틸리티 | 로컬 프로젝트 폴더의 index.html로 이동 |
| 스네이크 게임 | 브라우저 기반 클래식 스네이크 게임 리메이크 | 로컬 프로젝트 폴더의 index.html로 이동 |
| 홍보자동화 | 매장 사진 변환 + 채널별 홍보 문구 자동 생성 도구 | [GitHub 저장소](https://github.com/taegue00-cmyk/auto-generate-app) 로 이동 |

## 파일 구조

```
My-Portfolio/
├── index.html   # 페이지 구조 (카드 3개)
├── style.css    # 에디토리얼 스타일 (Playfair Display + Inter)
└── main.js      # 스크롤 등장 애니메이션
```

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.
